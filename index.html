Upload stok RM/PM

Pakai (daftar semua RM & PM dengan kolom QTY kosong), atau file export stok dari Odoo. Stok lama diganti seluruhnya dengan isi file. Kolom yang dicari: kode atau produk (mis. Product, Internal Reference) dan qty (mis. On Hand, Quantity); baris dengan kode sama dijumlahkan.

Upload stok gantung

Stok yang ada tetapi tidak bisa dipakai. Pakai (daftar RM & PM, kolom QTY kosong) atau file sendiri dengan kolom kode dan qty. Isi lama diganti seluruhnya. Di Proyeksi Stok: Stok Tersedia = Stok Awal − Stok Gantung.

Upload rencana produksi

Pakai (kolom KODE + week "W1 NOVEMBER 2026"), sheet PLAN WEEKLY dari template, atau file Unduh rencana. Bulan yang ada di file diganti seluruhnya; bulan lain tidak berubah. Kode yang tidak ada di DATABASE tetap disimpan tetapi diberi peringatan.

Memuat data CSL…

Customer Service Level per bulan

Rincian (Rp juta)

CSL = DO terkirim di bulan yang sama dengan SO ÷ SO. CSL + OS = semua DO terkirim di bulan itu (termasuk sisa SO bulan sebelumnya) ÷ SO, sama seperti Excel — bisa lebih dari 100%.

Memuat data CSL…

Rp juta. FCT = forecast Rupiah per region (diisi manual — klik baris bulan untuk mengubah). DO = semua DO terkirim di bulan itu (DO + OS), seperti REVIEW ALL di Excel. GAP = FCT − SO.

Memuat data CSL…

Pcs. FCT dari forecast; SO menurut bulan SO; DO = terkirim di bulan yang sama; DO-OS = SO bulan itu yang terkirim di bulan berikutnya.

Memuat data CSL…

Sisa SO = qty di DO yang belum Delivered (Ready to Deliver, Waiting Availability, …). DO Cancelled ditampilkan terpisah kecuali dicentang.

Memuat data CSL…

Pivot per nomor SO seperti sheet AMOUNT CHECK: Amount SO, Amount DO (terkirim di bulan SO), Amount DO-OS (terkirim bulan berikutnya), dan sisa. Klik baris untuk melihat rincian produk dan DO. Crosscheck dengan file Delivery Report menyusul saat file eksternalnya ada.

Memuat data CSL…
Bulan dipakai:

Total per bulan

Forecast vs SO (pcs) semua SKU dalam status ini.

Klik baris untuk melihat FCT vs SO per bulan. Tanpa-nol = bulan dengan SO 0 tidak dihitung. Tipe demand: ADI ≤ batas & CV² ≤ batas = Smooth; ADI > batas = Intermittent; CV² > batas = Erratic; keduanya = Lumpy (batas di PARAMETER).

Memuat data CSL…

Statistik dari menu Analisa Forecast (12 bulan sebelum bulan FCT, sesuai centang bulan di sana). Final suggest = rata-rata 5 aturan + buffer (safety stock). Arahkan kursor ke judul kolom untuk melihat rumusnya.

Memuat data CSL…

TOP 10 SKU menurut qty SO (pcs) pada bulan-bulan tiap musim. Bulan musim diatur di tab PARAMETER (MUSIM:…) — klik judul musim untuk mengubah.

Memuat data CSL…

Upload SO

Export Odoo sale.order apa adanya. SO yang ada di file diganti seluruh barisnya; SO lain tetap. Upload SO dulu, baru DO.

Upload DO

Export Odoo stock.picking.out apa adanya. DO yang ada di file diganti (status ikut terbarui). DO yang SO-nya belum pernah di-upload tidak disimpan dan dilaporkan.

Upload forecast (pcs)

Kolom BULAN, KODE, R1, R2, R3, R4, ONLINE (pcs). Bulan yang ada di file diganti seluruhnya. Forecast Rupiah per region diisi manual di menu Review Region.
