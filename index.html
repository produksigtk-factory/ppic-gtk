Perbarui data PO dari Odoo

Upload file export Odoo apa adanya. PO yang ada di file akan diperbarui, PO baru ditambahkan, dan PO lama yang tidak ada di file tetap disimpan.

  1. Pilih file PO-DET

    Detail baris PO (No PO, supplier, material, qty, harga). Nama file biasanya PO-DET_….xls.

  2. Pilih file PO-DEL

    Jadwal pengiriman (tanggal, qty jadwal, qty diterima, status). Nama file biasanya PO-DEL_….xls.

  3. Masukkan PIN dan kirim

    Boleh mengirim salah satu file saja. Data di Google Sheet langsung berubah setelah tombol ditekan.
